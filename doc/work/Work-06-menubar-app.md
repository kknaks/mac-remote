## 4. 기술 메모

> - MenuBarExtra는 SwiftUI App 프로토콜에서 사용
> - LSUIElement로 Dock 아이콘 숨김
> - NSWorkspace.shared.open(URL(string: "x-apple.systempreferences:...")!)로 시스템 설정 열기
